# Домашняя аптечка

Мобильное приложение для контроля домашней аптечки и сроков годности медикаментов.

Разработано в рамках лабораторных работ по дисциплине «Разработка программных приложений для iOS и iPadOS» (вариант 11).

## Описание

Приложение позволяет:
- вести учёт лекарственных препаратов;
- отслеживать сроки годности;
- фильтровать и сортировать список лекарств;
- просматривать детальную информацию о препарате;
- добавлять лекарства с помощью mock-сканера штрихкодов;
- получать предупреждения о лекарственных взаимодействиях.

## Технологии

- **Flutter** + **Dart**
- Архитектура: **Clean Architecture** + **MVVM**
- Локальная база данных: **SQLite** (пакет `sqflite`)
- Вспомогательное хранилище: статический **JSON**-файл
- Управление состоянием: `ChangeNotifier` + `ListenableBuilder`

## Структура проекта
lib/

├── data/             # DataSources, реализации репозиториев

## Основной функционал

| Функция | Описание |
|--------|----------|
| Главный экран | Список лекарств, фильтр по форме выпуска, сортировка по сроку годности |
| Детальная карточка | Остаток, дозировка, правила приёма, инструкция |
| Mock-сканер | Добавление препаратов по картинкам штрихкодов (для эмулятора) |
| Матрица несовместимости | Проверка конфликтов действующих веществ с выводом предупреждений |
| Журнал приёмов | Фиксация приёма лекарства и уменьшение остатка |
